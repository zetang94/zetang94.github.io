#### Research Interests
- **Code Summarization**
  - Code Summarization is a task that tries to comprehend code and automatically generate descriptions directly from the source code.
  Its main purpose is to help developers quickly understand the core functionality and logic of the code.
- **Code Completion** 
  - Code completion is a feature provided by many Integrated Development Environments (IDEs) and code editors.
  It automatically predicts and suggests the remaining part of a code statement as a developer types.
